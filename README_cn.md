# 可验证多智能体协同毕设原型

本文件与 `README.md` 保持同一说明口径：项目是本地最小多智能体协同系统，主线是**量化路由**、**受约束动态拓扑生成**、**结构化合约验证**和**历史失败率升级**。

核心流程：

```text
用户任务
-> 任务画像
-> 量化路由器
-> 拓扑规格
-> 受约束协作图
-> 多智能体协同
-> 真实大模型接口
-> 运行轨迹和最终结果
```

## 三个研究内容

1. **结构化合约验证机制**：每个智能体输出主张、证据和动作，验证器检查支持率、覆盖率和完整性。
2. **可量化路由驱动的受约束协作拓扑生成机制**：先由任务画像和输入需求得到能力需求，再按固定顺序和预算约束生成协作图。
3. **历史路由记忆与失败率升级机制**：相似历史任务失败率较高时，提高宏观协作等级。

## 受约束动态拓扑生成

三类拓扑是**宏观协作等级**，不是固定模板：

```text
单执行者级 -> 规划协作级 -> 审查修订级
```

实际执行图由能力组合生成。固定顺序为：

```text
规划者
-> 资料研究者
-> 工具执行者
-> 代码编写者/执行者
-> 测试者
-> 批判者
-> 修订者
-> 安全验证者
-> 验证者
-> 合成者
```

示例：

```text
简单解释任务：执行者 -> 验证者 -> 合成者
结构化比较任务：规划者 -> 执行者 -> 验证者 -> 合成者
材料依赖任务：规划者 -> 资料研究者 -> 执行者 -> 验证者 -> 合成者
工具查询任务：规划者 -> 工具执行者 -> 执行者 -> 验证者 -> 合成者
代码测试任务：规划者 -> 代码编写者 -> 测试者 -> 修订者 -> 验证者 -> 合成者
高风险审查任务：规划者 -> 执行者 -> 安全验证者 -> 验证者 -> 合成者
批判修订任务：规划者 -> 执行者 -> 批判者 -> 修订者 -> 验证者 -> 合成者
```
